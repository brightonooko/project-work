# Smart Parking Garage Management System

## My interpretation of the brief

The project is a database-centered system for managing a parking garage. It will manage parking spaces, customers, vehicles, reservations, parking entries and exits, tariffs, payments, subscriptions, and maintenance.
The main focus will be on designing a reliable relational database and implementing important business rules such as preventing double bookings, updating parking-space status, and calculating parking fees correctly. A simple web interface will be used to demonstrate the system.

## Why I am a good fit for this project

I am interested in database development and building systems that solve real-world problems. This project combines database design, backend development, transaction management, SQL, and performance optimization.
It also provides an opportunity to work with real business rules such as reservation conflicts and concurrent users.

## Relevant experience and background

I have experience working with web development, relational databases, SQL, backend technologies, and REST APIs. These skills can be applied to building the database, implementing business logic, connecting the web interface, and testing the system.

## Proposed approach

I would first design a normalized database with at least twelve related tables covering garages, floors, parking spaces, customers, vehicles, reservations, parking events, tariffs, payments, subscriptions, maintenance, and space states.
The main business operations would be implemented using database procedures and functions. These would include searching for available spaces, creating and cancelling reservations, handling vehicle entry and exit, and calculating parking fees.
The system would use transactions and appropriate locking or isolation mechanisms to prevent two users from reserving the same parking space at the same time.
A simple web interface would allow customers to search for available spaces, make and cancel reservations, and view their reservations. Operators would be able to view current occupancy and basic statistics.

## Initial plan

Design and normalize the database structure.
Implement tables, relationships, constraints, and business rules.
Create stored procedures and functions for core operations.
Implement reservation conflict prevention and transactions.
Add parking entry, exit, and fee calculation logic.
Generate realistic test data.
Develop complex SQL queries and basic statistics.
Build a simple web interface connected to the database.
Test concurrent reservations and database consistency.
Optimize selected queries using indexing and query improvements.
Measure and document the final system performance.

## Additional information

The project will be maintained in a Git repository with database scripts, sample data, setup instructions, and documentation.
The main focus will remain on the database and its business logic, while the web interface will provide a simple way to demonstrate the functionality.
Future extensions could include EV charging spaces, license-plate recognition, dynamic pricing, online payments, or a more advanced operator dashboard.
