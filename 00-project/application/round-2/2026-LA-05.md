# Language Learning Assistant with Individual Progress Tracking

## My interpretation of the brief

The project is a database-centered language learning system for learning either English or German. It will store learning items such as words, meanings, example sentences, topics, and difficulty levels, together with each user's practice history and results.

The main feature is that the system uses a learner's previous performance to decide which words or expressions they should practice next. Items answered incorrectly or not practiced recently can receive a higher priority.

## Why I am a good fit for this project

I am interested in developing practical applications that use data to provide personalized functionality. This project combines database design, SQL, backend development, and simple decision-making logic.

It also allows me to demonstrate how a database can use historical user data to provide personalized learning recommendations.

## Relevant experience and background

I have experience working with web applications, relational databases, SQL, backend technologies, and REST APIs. These skills can be used to design the database, store practice history, implement the learning-priority logic, and connect the system to a simple user interface.

## Proposed approach

I would first design a normalized database with at least ten related tables covering users, learning items, words, meanings, example sentences, topics, difficulty levels, practice sessions, exercises, answers, and learning states.

The main feature would be a database function or stored procedure that calculates a priority score for each learning item. The score would consider factors such as previous correct and incorrect answers, number of repetitions, difficulty, and how long it has been since the item was last practiced.

I would implement two selection methods, such as a simple rule-based method and a weighted-priority method, and compare their results.

A simple web interface would allow users to start a practice session, answer questions, and view their progress. The interface would receive the practice sequence from the database rather than calculating it itself.

## Initial plan

Choose English or German as the target language.
Design and normalize the database structure.
Implement learning items, users, topics, and difficulty levels.
Record practice sessions, answers, and learning history.
Create the learning-priority calculation.
Implement two methods for selecting the next practice items.
Develop progress and performance queries.
Generate realistic test data for practice history.
Build a simple web interface for practice and progress.
Optimize important database queries.
Compare the two selection methods and document the results.

## Additional information

The project will be maintained in a Git repository with database scripts, sample data, setup instructions, and documentation.

The main focus will be on how the database uses previous learning results to decide what the user should practice next, rather than building a large e-learning platform.

Future extensions could include pronunciation exercises, audio materials, reminders, additional exercise types, or machine-learning-based recommendations.
